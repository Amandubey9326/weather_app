# Weather App

A simple and responsive weather application built with React that allows users to search for a city and view real-time weather conditions using the OpenWeatherMap API.


# Features

🔍 Search weather by city name

📍 Displays temperature, humidity, wind speed, and weather description

🌡️ Supports metric (°C)  units

🕒 Real-time weather data

💡 Responsive UI (mobile-friendly)
